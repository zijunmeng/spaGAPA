## 六、工程教训（今日新增）

1. **FASTQ 0-indexed 序列行 = i%4==1（不是 2）**——Python enumerate 0 基导致系统性读错行，影响了所有 location 条码匹配（修复后 0%→78.7%）
2. **ENA 多段大文件 = 必须全量读取后再判断匹配**——采样 0.56% 会假阴性（location 条码匹配教训）
3. **mappy Python 单线程 = 不可用于 >10M 读段**——minimap2 命令行 16 线程快 ~50×
4. **fasterq-dump 输出命名不总带 _1 后缀**——单端 run 输出无后缀，链脚本需兼容
5. **NCBI prefetch 默认 --max-size 20G**——大于此值的 run 需显式 --max-size

## 十、外审揭示的关键技术问题详情

### 1. GP 输出非法值（模型失配）

`SourceData_Fig5E_gp_imputed.csv` 检查：
| 基因 | 超界 spots | 值域 |
|---|---|---|
| Gdap2 | 39/260 | -0.298 ~ 1.177 |
| Tor3a | — | -0.287 ~ 1.159 |
| Pcdhb21 | — | -0.162 ~ 1.196 |
| Trim16 | — | min = -0.179 |

**根因**：Gaussian likelihood 对 bounded proportion 数据的模型失配。
**修复**：logit-space GP（z = logit(p)，latent GP，inverse-logit 回 [0,1]）或 Beta likelihood / beta-binomial / count-aware model。

### 2. Conditional miscalibration（应提升为核心发现）

`SourceData_Fig4E` 检查：
| 条件 | Nominal | Observed |
|---|---|---|
| Mouse colon low-expr | 90% | **74.5%** |
| Visium liver high-expr | 80% | 80.9% |
| Visium brain high-expr | 80% | 80.9% |
| Visium kidney high-expr | 80% | 83.9% |

**行动**：不再弱化——提升为 "Global conformal calibration is insufficient for heterogeneous spatial APA data; spaGAPA therefore provides locally adaptive or stratified calibration." 这成为论文的 intellectual center。

### 3. Mean 胜 GP（应转为多目标叙事）

| 方法 | GSE183456 RMSE | GSE220442 RMSE |
|---|---|---|
| **mean** | **0.0799** | **0.0918** |
| spaGAPA-GP | 0.1219 | 0.1241 |
| spatial-KNN | 0.1469 | 0.1430 |
| stAPAminer | 0.2082 | 0.1749 |
| spvAPA | 0.2723 | 0.2720 |

但 spatial fidelity：mean=0 / GP=0.42 / KNN=0.91

**新叙事**："Point accuracy alone favors global shrinkage, whereas spatially informative reconstruction requires a different operating point."

### 4. Moran's I recovery 异常

| 方法 | Spatial fidelity | Moran's I recovery |
|---|---|---|
| mean | 0 | **0.88** |
| GP | 0.42 | **-0.28** |

反直觉：mean 无空间变异却有高 Moran's recovery；GP 有空间变异却负 recovery。可能是 metric 定义/normalization 问题。**必须重审或删除。**

### 5. 12.7M test entries ≠ 独立证据

空间相关 + gene dependence + spot dependence → 有效独立样本远小于 12.7M。**统计单位应提升到 sample/section level。** 正文核心图应报 per-sample coverage + deviation distribution + median/IQR + worst case + cluster/bootstrap CI。

### 6. AD 伪重复

S11 自我审计已发现：spot-level t-test 91 significant vs donor-level 0 significant。
正文不能用 2v1 的 407 spot-level FDR genes 作为疾病差异 APA 证据。**GSE233208（24 库，多样本）是解决此问题的关键。**

## 十一、审稿人评价摘要（接受）

> "The manuscript addresses an underexplored but increasingly relevant problem: uncertainty-aware analysis of sparse spatial APA measurements. The software appears mature and extensively evaluated across multiple platforms. The strongest aspect is the explicit calibration and selective-prediction framework. However, the present manuscript overstates several claims, and the methodological contribution is partly obscured by weaknesses in benchmarking and biological replication."

**审稿人正确识别的核心问题**：
1. 算法原创性："sparse GP + split conformal" 可能被评为 incremental
2. 生物学：2v1 AD 不能承担 confirmatory claim
3. 统计：exchangeability、bounded outcome、pseudoreplication

**审稿人认可的优势**：
1. 工程成熟度很高（CLI/API/可复现/SourceData/跨平台验证）
2. 数据量已足够
3. 主动暴露负结果增加可信度
4. Risk-coverage 是最认可的模块（应升格）

**最重要的战略建议**：
> "停止继续追求'所有指标都赢'，开始把 spaGAPA 定义成一个'知道自己什么时候可能错、并能量化这种错误'的空间 APA 方法。"

> "Marginal calibration is easy; conditional reliability is the real problem. This is the intellectual center of the paper."
