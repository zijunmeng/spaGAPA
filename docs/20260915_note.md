## 五、工程教训（已沉淀为标准流程）

1. ENA/CDN 大文件多段下载 = **必须 gzip -t/md5 内容级校验**（三次实证：字节数对 ≠ 内容好）；损坏即切 NCBI prefetch
2. nohup 壳 PID ≠ python PID——监控用 `pgrep -f` 不用缓存 PID
3. 38M 次 pandas `.iloc` 慢路径 → 向量化 remap；17GB toarray → 稀疏行写
4. FASTQ 解析：0 基枚举序列在 `i%4==1`（曾用 ==2 踩坑）
5. 推荐任何新平台数据前，先验证捕获化学与 APA 兼容性（poly-dT ✓ / 探针 ✗）
