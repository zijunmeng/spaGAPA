## 一、项目定位

spaGAPA 是首个针对空间转录组学的选择性多聚腺苷酸化（APA）分析工具，提供从稀疏 PAS 矩阵到校准不确定性空间 APA 景观的端到端管线。

### 核心创新（按强度排序）

1. **分布无关 conformal 校准**——首个在空间 APA 分析中提供有限样本边际覆盖保证（交换性假设下）的工具。19+ 样本、12.7M 测试点、覆盖偏差全部 ≤0.67pp，跨 Visium 55µm → Stereo-seq bin200 → **HD 2µm** 27.5 倍线性分辨率范围均精确。

2. **被弃权条目恢复**——P0-2 实验证明：过滤策略（Longcell 式）在极端稀疏下丢弃 55% 条目；spaGAPA 的 GP 插补以 RMSE 0.228 恢复这些条目并附带覆盖保证。

3. **Risk-coverage 分诊**——不确定性排序具有真实信号：剔除 20% 最不确定条目降低 RMSE 23.3%（vs 随机剔除 0.1%）。

### 诚实边界（Limitations，10 条全部有实验数据支撑）

1. GP 逐点 RMSE 不敌 per-gene mean（0.122 vs 0.080）——价值在区间、完整性与梯度恢复，非点精度
2. 不确定性与真误差相关性温和
3. 边际≠条件覆盖（高表达 bin 欠覆盖 ~82%）
4. Stereo-seq mask 质量瓶颈
5. 跨样本迁移方差（最大单对 11.8pp）
6. 深度非单调（80k spots + 500 inducing 时容量限制）
7. mm39/mm10 坐标陷阱
8. sAPA-RegNet 留出验证 0.372 → 降级至补充材料
9. 无监督（vs spvAPA 监督式）
10. 批次校正待评估

### 六项独立实验

| 实验 | 内容 | 结果 |
|---|---|---|
| E1 模拟 | 54 条件 × 3 深度 × 3 稀疏 × 3 种子 | conformal ±0.003；raw GP 过覆盖 ~100%（证明校准必要） |
| E2a 正交 | PolyA_DB v4.1 ±50bp，18 样本 | precision 74.7%（29.7× 富集），recall 5.3%（基因限制分母） |
| E3 迁移 | 110 LOO 跨样本 | 平均衰减 <0.4pp；跨组织最大 11.8pp（如实报告） |
| E2b 长读 | Spl-ISO-Seq 空间 ONT 正交 | minimap2 比对中（79GB，16 线程） |
| P0 对抗 | 边界损害/过滤基线/分块 conformal | 边界 ✓（0.984）；过滤 ⚠️（GP 输 mean 2.3× 但恢复被弃条目）；分块 ✗（+3.06pp 保守过覆盖） |
| P2-1 留出 | sAPA-RegNet 200 次随机留出 | 0.372（低于随机 p=9.2e-12）→ 预注册降级 |

## 四、架构

```
spagapa/
├── core/           APADataset, APASite（无算法依赖）
├── io/             BAM/坐标/矩阵读取
├── spatial/        KNN/radius/Delaunay 图构建
├── calling/        空间验证 + 质量过滤
├── imputation/     稀疏 GP + split-conformal + Mondrian（核心创新）
├── bioml/          多视图图 + Leiden 域检测（二级创新）
├── analysis/       差异 APA / SVAPA / 批次校正
├── benchmark/      模拟 + 真实基准
├── visualization/  绘图
├── presets.py      形状驱动分发（auto/standard/highres_accuracy/highres_fast）
├── pipeline.py     SpaGAPA 七步编排器
└── cli.py          click CLI（run/impute/diff/plot）
```

**API**：
```python
from spagapa import SpaGAPA
result = SpaGAPA(analysis_preset="highres_fast").run(
    apa_matrix="matrix.csv", coordinates="coords.csv")
# result['imputed_values'], ['uncertainty'], ['domains'], ['apa_indices']
```

**CLI**：
```bash
spagapa run -m matrix.csv -c coords.csv --analysis-preset auto -o output/
```
