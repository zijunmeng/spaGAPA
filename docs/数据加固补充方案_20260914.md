## 支柱一：对抗性验证（P0）

### P0-1 域边界损害测试

- **回应偏差**：B4（"插补 vs 过滤"之争未经实验回答；RBF 平滑假设未验证）
- **问题**：GP 的 RBF 平滑假设在真实生物学边界（皮层分层）处是否制造虚假信号？
- **数据**：MOB Visium（5 层注释已有）+ DLPFC（7 层，SpatialLIBD 公共）——两个组织独立验证
- **方法**：
  1. 遮蔽 20%（per-gene，种子 42）
  2. GP 插补
  3. 误差按**到最近层边界的距离**分层：`<50µm / 50-150µm / >150µm`
  4. 报告各层 RMSE + Kruskal-Wallis 检验
- **可能结果 A**：边界附近误差显著升高（>2×）→ **证伪平滑假设** → 论文如实报告 + 测试边界感知核（用 BioML 域标签修正 lengthscale）
- **可能结果 B**：误差无边界效应 → RBF 假设成立 → 写入论文作为假设验证
- **预注册判定线**：边界近/远误差比 <1.5× 为通过
- **成本**：1 天（纯现有数据）

### P0-2 过滤/弃权基线（最关键的一项）

- **回应偏差**：B2+B4（主指标输给 mean；领域选过滤可能有正当理由）
- **问题**：插补必须打赢或打平"不插补+过滤"才有存在权
- **方法**：实现 Longcell 式三段基线：
  1. 硬过滤（≥30 spots × 10 reads + 置信过滤）
  2. meta-pooling（域内共享信息）
  3. 只在存活条目上报告
- **对比矩阵**（同一遮蔽 truth set）：

| 方法 | 存活条目比例 | 存活条目 RMSE | 被丢弃条目恢复精度 |
|---|---|---|---|
| GP 插补 | 100% | 待测 | 待测（带覆盖保证） |
| 过滤弃权 | 预计 5-20% | 待测 | N/A（全弃权） |
| per-gene mean | 100% | 0.080（已知） | 无区间 |

- **预期定位**：插补的价值 = **恢复被过滤丢弃的 80-95% 稀疏条目**，且带覆盖保证
- **预注册判定线**：被丢弃条目恢复 RMSE < 过滤组全弃权基线，且覆盖率达标
- **未通过时**：重新定位插补叙事或加显著警告
- **成本**：1-2 天

### P0-3 空间分块 conformal 检验

- **回应偏差**：11.2（"spatial-block split 验证过覆盖率"声明未经核实）
- **问题**：conformal 可交换性假设在空间自相关下是否被实质违反？
- **方法**：校准/测试划分从随机改为**空间分块**（四象限 / 按域划分），测 80/90/95% 覆盖偏差
- **预注册判定线**：分块覆盖偏差 <1pp 为通过（交换性违反实际无害）
- **未通过时**：写入局限 + 测试 spatially-weighted conformal
- **成本**：半天

## 支柱二：统计加固（P1）

### P1-1 E2a 补召回率
- 反向计算：PolyA_DB 组织相关位点中 spaGAPA 找回多少（precision 74.7% 已有，补 recall + F1）
- 成本：半天

### P1-2 等功效 downsampling（NC 文化）
- 100%/75%/50%/25% 下采样 × ≥20 重复，所有指标带 mean±CI
- 参照：Spl-ISO-Seq 用 100 次重复；我们至少 20
- 成本：1 天

### P1-3 多种子稳定性
- 现有 3 种子扩到 ≥5，主表全部指标报 mean±SD
- 成本：半天

### P1-4 逐条目预测力如实呈现
- 论文正文放 entry-level 相关（~0.04）+ 区间宽度分布
- 卖点重写为 "risk-coverage 分诊：剔除 20% 最不确定条目后 RMSE 降 23%"
- **以最强证据领导叙事**
- 成本：改写 1 天

### P1-5 数据集计数改口径
- 全文弃用"17 样本"话术，改"4 项研究 / 7-8 个独立语境"
- 附独立语境明细表（研究 → 组织 → 样本数 → 角色）
- 成本：改写即可

## 支柱三：生物学锚定（P1-P2）

### P1-6 AD 2v1 + 文献方向锚定（E4 峰恢复后重跑）
- E3 + E4（恢复后峰集）vs F5 WT
- 显著基因与**已发表 AD APA 签名**比对（文献方向一致性 + 二项检验）
- 外部锚定而非自说自话
- 预注册判定线：方向一致性 >60%（p<0.05）
- 成本：E4 恢复跑完 + 1 天

### P2-1 sAPA-RegNet 留出验证或降级
- 留出 1/3 RBP 不参与任何阈值选择 → 在留出集上测方向一致性
- 不过关则**主动从主文降级到补充材料**
- 成本：1-2 天 / 降级零成本

### P2-2 TCGA 计算正交验证
- TCGA-LUAD/LIHC + APAatlas 的 APA-生存关联
- 检验空间可变 APA 基因是否富集于预后相关集合（超几何检验）
- 成本：1-2 天

### P2-3 3M 疾病进程分析（管线完成后）
- 3M AD vs 5M AD 的 APA 漂移 + Apoe/Trem2 分型相关
- 成本：管线完成后 1 天

## 执行排程

```
本周（P0 三项，全部现有数据）：
  Day 1  P0-1 边界测试（MOB+DLPFC）＋ P0-3 分块 conformal
  Day 2  P0-2 过滤基线（决定叙事走向的关键实验）
  Day 3  P1-1 召回率 ＋ P1-3 多种子 ＋ P1-5 口径修正
  Day 4  P1-2 downsampling ＋ P1-4 论文改写

并行（管线已在跑）：
  E4 峰恢复 → AD 2v1 重跑（P1-6）
  3M_E1 scAPAtrap → E2 → Phase 3 完整版（P2-3）

下周（视 P0 结果）：
  P0-1 若证伪 → 边界感知核开发（+2-3 天）
  P2-1 留出验证 / P2-2 TCGA
```

## 预注册判定标准汇总

在跑之前先写下判定线，避免事后合理化：

| 实验 | 通过线 | 未通过时的动作 |
|---|---|---|
| P0-1 | 边界近/远误差比 <1.5× | 报告 + 边界感知核 |
| P0-2 | 被丢弃条目恢复 RMSE < 全弃权基线，覆盖率达标 | 重新定位叙事或加警告 |
| P0-3 | 分块覆盖偏差 <1pp | 写入局限 |
| P1-6 | 文献方向一致性 >60%（二项 p<0.05） | 如实报告分歧 |
| P2-1 | 留出 RBP 方向一致性显著 | 降级到补充材料 |

## 方案本质

把 v2 审计里的每一条"可能被打"的点，变成**我们已经打过并有答案**的点。
审稿人问到的每个问题都有实验编号可引。
