## 二、文库结构（官方文档 + 实测共识双源验证）

### 官方序列（xlsx）

```
芯片捕获寡核苷酸 5'→3':
[24nt 固定 TCTTTCCCTACACGACGCTCTTCCGATCT]（= TruSeq Read1 尾部）
[30×N 空间条码]
[21nt 固定 GTTCGCAACATGTCTGGCGTCATAGAATTC]
[10×N UMI（官方标称）]
[T30 VN oligo-dT] → 捕获 mRNA polyA
```

### 实测修正（KC1 20 万读 QC + 10 万读锚定共识）

```
R1 (150bp) 实际布局:
[0:37)    空间条码（实测 ~37bp，官方标 30——边界精修中）
[37:58)   固定序列（锚 CAACATGTCTGGCGTCATAGA 起始位置 mode=37）
[58:63)   AATTC（官方 21mer 尾部）
[63:~83)  ★文档未注明的第二恒定段 GCAGTCCAGTACGACTCACT(~20bp)
[~83:95)  随机 ~12bp（真实 UMI 窗口，非官方所说位置）
[~91:120) oligo-dT 残留（polyT 中位长 34，浮动）
[91:150)  mRNA 3' 末端 ~60bp → PAS 切割位点 = polyT/转录本连接处
```

**关键验证数字**：63.9% 读段含完整捕获结构；条码多样性 122,882 唯一/12.8 万（每位点 ~1 读，空间条码特征 ✓）；polyT@91 与结构前缀总和完全闭合。

### R2（150bp）

起始大量接头读穿（短插入）：TruSeq P7（`GAATCTCGTATGCCGTCTTCTGCTT`）、SMART/TSO（`GTGGTATCAACGCAGA...`，top1 724 次错峰）、Nextera universal——与官方"cDNA_R = TSO 序列"一致。R2 为 cDNA 5' 端读段，对 APA 非必需。

### 误判澄清（取证过程记录）

1. i5 index 恒定（CAAGCTAG）+ i7 少数真值多变体 → 双 index = 样本标签，**不是**空间条码
2. KC 读名坐标（R001C001:Y:X）= **流式坐标**（同条码跨多坐标已证）→ 不能当空间坐标用
3. 空间条码经 TruSeq Read1 引物**直接读进 R1 前缀** → 不需要 I1/I2 index 读（早先判断有误，已纠正）

## 四、唯一缺口与获取途径

**需要：9 月批次芯片的「30bp 条码 → (x,y)」映射文件**

两条获取路径（按优先）：

1. **向真迈（GeneMind）/芯片提供方索要该批次 manifest**——芯片设计文件是标准交付物
2. **确认 9 月批次是否做过芯片条码直读测序**（建库前的常规质控步骤）——若有，其 FASTQ 格式应与 6 月文件相同（读名含坐标 + 35bp 条码序列），把那个文件给我即可

拿到后管线 1-2 天出首个结果：

```
KC1 R1 解析（已就绪）
  → 条码纠错（Hamming 1mm，30bp 白名单）
  → 转录本 3' 端比对 Sscrofa11.1 → PAS
  → UMI 去重 → 条码→坐标 → 1µm→8µm 聚合
  → scAPAtrap → spaGAPA conformal + BioML 域检测
  = 猪 × 自研 1µm 平台 × 空间 APA（领域首次，分辨率超 Visium HD 2µm）
```

## 五、科学定位与价值

1. **第 4 物种**（人/鼠/大鼠 → +猪）：跨物种主张直接升级
2. **第 3 平台**（Visium/Stereo-seq → +自研 1µm）：caller/平台无关性再添一级，且是**国产自研平台**（合作叙事）
3. **最高分辨率**：1µm 原生（聚合后 8µm ≈ 单细胞尺度）> Visium HD 2µm——"极端稀疏下 conformal 区间价值"论点的最强场景（P0-2 已证过滤法在此场景弃权 95%+ 条目）
4. **无菌猪模型**：疾病/移植研究热门模型，无公开空间 APA 数据——数据本身即首创
5. 论文落点：Methods 扩展（平台适配案例）或独立合作短文（平台方联合）

## 六、风险与注意事项

| 风险 | 缓解 |
|---|---|
| R2 接头污染严重（短插入多） | 管线仅依赖 R1；R2 若用于融合/全长需 cutadapt |
| 条码白名单纠错需 manifest 支持 | manifest 内含全部合法条码；无 manifest 不可纠错（假条码→位置错配） |
| 文档未注明的 ~20bp 第二恒定段 | 来源待平台方确认（设计变更 or 文档简化）；解析器按实测共识已适配 |
| PAS 侧仅 ~60bp 转录本（150-91） | 足够 3'UTR 唯一锚定（Visium 90bp 的一半已可用）；多比对读段丢弃并计数 |
| KC3 极小（0.25GB） | 定位为 QC 库，不进主分析 |
