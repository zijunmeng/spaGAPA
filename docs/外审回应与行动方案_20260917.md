# spaGAPA 外审意见回应与行动方案

> 基于外部审稿人 2026-09-17 详细审查（覆盖项目总结、7 主图、SourceData、conformal 表、scalability 数据、AD differential APA）
> 审稿结论：Major Revision；NAR 存在拒稿风险
> 本文档：逐条回应 + 优先级行动方案

---

## 一、完全接受并立即修正的问题

### 1. "首个空间 APA 工具" — 撤回 ✅

**审稿人正确**。stAPAminer（2023, GPB）、spvAPA（2025, BIB）、SpatialAPA（2026）均已发表。

**修正为**：
> "spaGAPA is an uncertainty-aware spatial APA analysis framework that combines scalable spatial imputation with finite-sample conformal calibration. To our knowledge, it is the first spatial APA framework to provide conformal prediction intervals with finite-sample marginal coverage guarantees under exchangeability."

**已在所有文档中执行搜索替换。**

### 2. "四个数量级分辨率梯度" — 数学错误 ✅

55µm/2µm = 27.5×（1.44 个数量级线性；2.88 个数量级面积）。

**修正为**：
> "across a 27.5-fold linear spatial-resolution range, from 55-µm Visium spots to 2-µm Visium HD bins"

### 3. GP 输出非法 APA 值 — 模型失配 ✅

`SourceData_Fig5E` 中确认存在负值和 >1 值（如 Gdap2: -0.298~1.177，39/260 spots 超界）。

**行动**：实现 **logit-space GP**（`z = logit(p)` 变换后做 GP，逆变换回 [0,1]）。这同时修复问题和创造算法贡献。

### 4. HD 验证用的是 mean 而非 GP — 必须补 ✅

`hd_conformal_quick.json` 的 method 字段明确写了 "per-peak mean"。这只证明了 conformal 层在 HD 规模工作，不能声称 GP 在 HD 验证。

**行动**：补一个真正的 sparse-GP + conformal HD benchmark（5k/20k/50k/100k spots × 100-300 peaks，报告 GP/mean/KNN 的 RMSE + coverage + width + runtime）。

### 5. AD 2v1 伪重复 — 降温措辞 ✅

2 AD vs 1 WT，spot-level 检验。且 S11 已自己发现 donor-level 0 significant。

**修正**：正文改写为 "A descriptive spatial APA case study identified 407 spot-level candidate shifts; these should not be interpreted as population-level AD associations because biological replication was insufficient." Camk1d 降为 "illustrative candidate"。

### 6. DAM marker 未归一化 ✅

raw count ratio 不能直接解释为 fold change。降级为 "marker-expression sanity check"。

## 二、接受并需升级的统计问题

### 7. Exchangeability 假设 — 论文核心统计学问题

**审稿人的关键质疑完全成立**：空间相关、gene dependence、spot dependence 下，exchangeability 为何成立？12.7M test entries 不是独立证据。

**行动方向**（即审稿人建议的第 5 点算法升级）：
- **Mondrian/hierarchical conformal**：按 gene expression / local sparsity / spatial density 条件化
- **Spatial-block conformal**：让 calibration unit 与空间依赖结构一致
- **Weighted conformal under domain shift**：针对跨样本 prediction

**已有零件**：global + locally adaptive + Mondrian + spatial block + LOOCV + conditional coverage 数据全部在手上。**缺的是统一统计框架**。

### 8. Conditional miscalibration — 提升为核心发现

审稿人从 `SourceData_Fig4E` 发现：低表达 bin 90% nominal → 74.5% observed。这确实是重要科学事实。

**行动**：不再弱化，提升为：
> "Global conformal calibration is insufficient for heterogeneous spatial APA data; spaGAPA therefore provides locally adaptive or stratified calibration."

这成为论文的 **intellectual center**。

### 9. Moran's I recovery 指标异常 — 必须重审或删除

mean spatial fidelity = 0 但 Moran's I recovery = 0.88；GP fidelity = 0.42 但 Moran's I = -0.28。反直觉。

**行动**：审查定义；若无法清楚解释，删除该指标。

## 三、接受并需重构的 benchmark 问题

### 10. Mean 胜 GP — 重构叙事

审稿人建议的核心转向：**从单指标竞争改为 multi-objective trade-off**。

**行动**：Fig.2 重构为 accuracy–spatial fidelity–calibration 的 **Pareto front**。核心叙事变为：
> "Point accuracy alone favors global shrinkage, whereas spatially informative reconstruction requires a different operating point."

### 11. Scalability 混杂 — 重做

gene 数变了（2000→500）+ runtime 非单调（15k: 276s > 42k: 162s）。

**行动**：固定 G=500，N=1k/2k/5k/10k/20k/50k/100k × 5 repeats，报 median±IQR + peak RAM。单独做 fixed-N varying-G。

### 12. spvAPA FAILED 不公平 — 补两种模式

`future.globals.maxSize` 是 R 配置问题。**行动**：补 optimized settings 下的 benchmark。

### 13. P0 "被弃条目恢复" — 语言收紧 + 补空间结构证据

仅 RMSE 不足以称 "recovery"。**行动**：补被过滤条目上的 spatial gradient / domain recovery / Moran structure。

### 14. PolyA_DB recall 5.3% — 补 detectable recall

**行动**：补 expressed-gene recall / coverage-matched recall，同时报 precision + enrichment。

## 四、战略转向（最重要）

### 旧叙事（废弃）
```
1. GP imputation 好
2. Conformal 校准准
3. Graph domain 检测强
```

### 新叙事（采纳）
```
Contribution 1 — Reliable completion of sparse spatial APA matrices
  （不声称 point RMSE 最优；强调 coverage + spatial structure + completeness + scalability）

Contribution 2 — Calibrated uncertainty and selective prediction
  （最强贡献：marginal coverage + local failure modes + risk-coverage + cross-sample）

Contribution 3 — Spatial APA patterns that survive uncertainty-aware analysis
  （domain recovery + Stereo-seq + replicated biological application 为下游证据）
```

**一句话定位**：
> "spaGAPA is a spatial APA method that knows when it might be wrong and can quantify that error."
