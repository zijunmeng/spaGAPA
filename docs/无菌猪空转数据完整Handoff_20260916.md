## 三、端到端管线（新会话直接执行）

### Step 1：构建条码→坐标映射表

```python
# 从 2D260415021A1.fq.gz 提取 (barcode, X, Y)
import gzip

mapping = {}
with gzip.open("/s2/SHARE/spatial/20260604重庆医科大/2D260415021A1.fq.gz", "rt") as f:
    header = ""
    for i, line in enumerate(f):
        if i % 4 == 0:
            header = line.strip()
        elif i % 4 == 1:  # 序列行（0-indexed，勿用 i%4==2！）
            bc = line.strip()[:32]
            parts = header.split(":")
            try:
                x, y = int(parts[-2]), int(parts[-1])
                mapping[bc] = (x, y)
            except ValueError:
                pass  # 跳过含 N 的 header

# 保存为 TSV: barcode\tX\tY（~87M 行）
```

### 注意事项

## 六、常见坑（务必避免）

| 坑 | 解法 |
|---|---|
| FASTQ 序列行索引 i%4==2 | **用 i%4==1**（Python 0-indexed） |
| 条码不做 revcomp | **必须 revcomp** 才能匹配 location |
| 只采样 location 文件 | **必须全量读取**（70M+ 条码，采样会假阴性） |
| xlsx 标注 30bp 条码 | 实际是 **32bp**（以工作代码和实测为准） |
| 芯片复用 | 不可能，一次性耗材 |
| R2 直接用 | 需 cutadapt 修剪接头（APA 不依赖 R2） |
| 6 月文件≠9 月芯片 | **不是问题**——已确认同一芯片 2D260415021 的 A1 区 |
