## 附：关键修复教训（写代码前必读）

1. 未引用 heredoc 内所有 `$` 必须 `\$` 转义（两次 0 字节 R 文件）
2. monkey-patch 必须真签名 + 类型守卫 + 正确返回类型（路径 vs 对象）
3. scAPAtrap init 目录守卫：干净重启或 rename-hide，勿用 toCheck=FALSE
4. SAW 可视化步骤对旧 SN 格式装饰性崩溃——以 target.bam 判成功
5. 大内存导出一律流式（rda → writeLines 分块）
6. 自动重启守护脚本用完即删（幽灵重启是三次事故根源）
