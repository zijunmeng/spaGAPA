# Milestone 9: High-Resolution spaGAPA

## 1. Goal

spaGAPA should remain accurate, biologically consistent, uncertainty-aware,
and CPU-feasible when spatial resolution increases from hundreds of spots to
thousands or more spatial bins.

The BIB-level claim is:

```text
spaGAPA supports spatial APA analysis across standard and high-resolution
spatial transcriptomics by combining scalable sparse/block GP imputation with
multi-view BioML graph recovery, while preserving uncertainty and downstream
APA interpretability.
```

This milestone explicitly keeps the project within the current constraint:

```text
No deep learning. No GPU requirement. Classical machine learning only.
```

## 2. Why High Resolution Matters

High-resolution spatial transcriptomics platforms can produce far more spatial
locations than classic Visium/ST:

- Visium HD-like binned data
- Slide-seq-like bead data
- Stereo-seq-like grid bins
- HDST-like high-density bins

For spatial APA, high resolution is both an opportunity and a risk:

1. Spatial structure is richer:
   - local microdomains
   - fine tissue boundaries
   - gradients
   - rare niches
2. APA measurements are sparser:
   - smaller bins have fewer reads
   - 3-prime/poly(A) coverage is weaker per bin
   - missingness is more severe
3. Exact GP does not scale:
   - exact GP cost grows poorly with spot count
   - high-resolution analysis requires sparse, local, or block approximations
4. Biological validation changes:
   - layer ARI is useful for brain datasets, but high-resolution data also
     needs boundary preservation, aggregation robustness, and local consistency

## 3. Scope

### In Scope

- High-resolution pseudo-bin simulation from an existing real spatial APA dataset.
- Sparse GP imputation on pseudo-bins.
- BioML multi-view graph recovery on pseudo-bins.
- Parent-spot aggregation recovery metrics.
- Runtime and memory measurement.
- High-resolution domain recovery against inherited tissue labels.
- Figure/table output for manuscript-ready diagnostics.

### Out of Scope for MVP

- Downloading large external high-resolution datasets.
- Full multi-caller APA site integration.
- GPU acceleration.
- Deep-learning graph neural networks or autoencoders.

## 4. Input Contract

The high-resolution benchmark uses the same prepared data contract as the
external validation runner:

```text
apa_matrix.csv          genes x spots APA usage matrix, NaN for missing
expression_matrix.csv   genes x spots expression matrix, optional but preferred
coordinates.csv         spot_id/barcode, x, y
metadata.csv            spot_id/barcode, layer/domain annotation
```

For pseudo high-resolution simulation:

- each parent spot is split into `k` pseudo-bins
- each pseudo-bin inherits the parent layer/domain label
- coordinates are jittered around the parent spot
- expression embeddings are expanded from parent spot embeddings with small noise
- APA truth is expanded from parent APA values with controlled micro-noise
- observed APA values are generated by applying capture probability, dropout,
  and measurement noise

## 5. Algorithm Strategy

### 5.1 Why Exact GP Is Not the High-Resolution Backbone

Exact GP remains valuable for small and moderate spatial datasets, but it is
not the high-resolution default because:

- it scales poorly with spot count
- repeated per-gene exact GP fitting becomes expensive
- high-resolution bins are noisy enough that local sparse approximations are
  often the pragmatic choice

### 5.2 High-Resolution spaGAPA Backbone

Initial sparse BioML diagnostic route:

```text
high-res APA matrix
  -> SparseGPImputer
  -> uncertainty
  -> MultiViewGraph(spatial + expression + APA)
  -> GraphRegularizedAPAFactorizer
  -> BioML spectral domain recovery
  -> downstream SVAPA / differential APA / aggregation validation
```

This direct transfer from standard-resolution BioML exposed an important
failure mode: pseudo-bin APA values are too sparse/noisy to be trusted as a
domain-graph view without extra safeguards. In the MOB pseudo-high-resolution
pilot, the direct `sparse_bioml` route improved over sparse GP but remained
weaker than expression KNN for layer recovery.

The high-resolution MVP therefore adds a decoupled route:

```text
observed high-res APA
  -> raw gene-mean fill
  -> SparseGPImputer + uncertainty
  -> conservative raw/sparse-GP value blend

expression matrix
  -> expression embedding
  -> expression-KNN APA proxy

coordinates + expression embedding + expression-KNN APA proxy
  -> highres_bioml spectral multi-view graph
  -> biological domain labels
```

The key design principle is:

```text
Use sparse GP to improve noisy APA value recovery, but do not force sparse-GP
APA distances to define high-resolution tissue domains.
```

The backbone remains CPU-friendly:

- sparse GP uses inducing points
- BioML uses sparse KNN graphs and low-rank factorization
- graph operations remain sparse
- all methods run without GPU

### 5.3 Future Multiscale Extension

After MVP, high-resolution spaGAPA should add:

1. Local block GP:
   - split tissue into overlapping blocks
   - run sparse GP per block
   - merge overlapping predictions
2. Coarse-to-fine graph:
   - coarse parent/region graph for global tissue structure
   - local high-resolution graph for boundary preservation
3. Adaptive graph weighting:
   - more spatial weight when expression is weak
   - more expression weight when APA is too sparse
   - uncertainty-aware downweighting of noisy bins
4. Aggregation-aware consistency:
   - high-resolution predictions should aggregate back to parent-level APA
   - parent-level biological structure should be preserved

## 6. Benchmark Design

### 6.1 Simulation Factors

The MVP benchmark varies:

- `subbins_per_spot`: number of high-resolution pseudo-bins per original spot
- `capture_rate`: probability that a gene-bin APA value is observed
- `dropout_rate`: additional dropout on top of capture loss
- `measurement_noise`: noise added to observed APA values
- `micro_noise`: true local variation among pseudo-bins

### 6.2 Methods

Initial method set:

```text
raw
expression_knn
sparse_gp
sparse_bioml
highres_bioml
```

Definitions:

- `raw`: gene-mean filled observed high-resolution matrix
- `expression_knn`: stAPAminer-like expression-neighbor imputation on pseudo-bin
  expression embeddings
- `sparse_gp`: spaGAPA sparse GP imputation without BioML
- `sparse_bioml`: spaGAPA sparse GP + BioML multi-view graph recovery
- `highres_bioml`: high-resolution-specific BioML route that decouples
  conservative APA value recovery from spatial/expression/APA-proxy spectral
  domain graph recovery

### 6.3 Metrics

Accuracy:

- RMSE on unobserved pseudo-bin values
- MAE on unobserved pseudo-bin values
- RMSE on all pseudo-bin values

Aggregation robustness:

- parent-level RMSE after aggregating pseudo-bins back to parent spots
- parent-level MAE

Biological consistency:

- inherited layer/domain ARI
- inherited layer/domain NMI
- purity
- pairwise Jaccard

Uncertainty:

- uncertainty-error Spearman correlation on unobserved pseudo-bin values
- mean uncertainty

Scalability:

- runtime
- peak RSS memory
- number of pseudo-bins
- observed fraction

## 7. Success Criteria

MVP success:

1. The high-resolution simulator runs from existing MOB prepared data.
2. `sparse_bioml` and `highres_bioml` complete on at least 1,000 pseudo-bins
   on CPU.
3. `highres_bioml` layer ARI/NMI exceeds `raw` and `expression_knn` in the
   pseudo-high-resolution pilot.
4. Sparse GP uncertainty is positively associated with prediction error.
5. Pseudo-bin RMSE is lower than raw or expression KNN.
6. Results are saved as reproducible tables and Matplotlib figures.

Manuscript-level success:

1. At least one high-resolution-like real or pseudo-real experiment is included.
2. Scaling plot shows runtime/memory as spot count increases.
3. High-resolution analysis supports the core spaGAPA narrative:

```text
Sparse, high-resolution APA measurements require uncertainty-aware spatial
statistical treatment rather than simple local averaging.
```

## 8. Risks

1. Pseudo high-resolution bins are not a substitute for true high-resolution APA.
   - Mitigation: present simulation as scalability/stress test, not biological discovery.
2. Inherited layer labels may over-simplify high-resolution microdomains.
   - Mitigation: add boundary/local smoothness metrics later.
3. Sparse GP currently supports RBF only.
   - Mitigation: treat high-resolution MVP as sparse RBF route; exact Matérn remains
     standard-resolution route.
4. BioML graph weights may need re-tuning for high-resolution data.
   - Mitigation: add graph weight sweep after the MVP runner is stable.


This creates two useful high-resolution modes:

1. **Accuracy mode**
   - `highres_bioml_gp_blend = 0.3`
   - best pseudo-bin RMSE in the current suite
   - preserves strong layer ARI/NMI
   - retains sparse GP uncertainty
2. **Fast-domain mode**
   - `highres_bioml_gp_blend = 0.0`
   - skips sparse GP when APA source is not `sparse_gp`
   - runtime drops to about `0.38s` in the current 320-bin pilot
   - keeps the same layer ARI/NMI as accuracy mode
   - gives raw-level RMSE and no sparse GP uncertainty

Runtime optimization implemented:

```text
If highres_bioml_gp_blend == 0 and highres_bioml_apa_source != sparse_gp,
skip sparse GP completely.
```

Additional optimization implemented:

```text
BioML spectral domain detector now keeps sparse affinity matrices sparse
instead of converting them to dense arrays.
```

The 8x pseudo-bin scenario exposes a remaining risk: layer ARI drops at larger
subbin expansion. This likely reflects over-fragmented inherited labels and/or
graph-neighborhood settings that are too local for larger pseudo-bin clouds.

Next high-resolution work:

- Add adaptive graph-neighbor selection for 8x and larger pseudo-bin settings.
- Add low-coverage/dropout-heavy gene strata.
- Add aggregation-aware objective or evaluation-driven model selection for
  parent-level RMSE.
- Compare sparse GP, block/local GP, and fast-domain mode on larger pseudo-bin
  scenarios.
- Validate on true high-resolution spatial transcriptomics data that preserve
  3-prime/poly(A) signal.
